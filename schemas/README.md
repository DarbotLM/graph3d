# graph3d contract schemas

This directory contains versioned machine-readable contracts shared by CLI, MCP, APIM, and SDK surfaces.

- `extraction-v1.schema.json` — extraction JSON contract.
- `graph-v1.schema.json` — graph node-link contract.
- `cli-envelope-v1.schema.json` — CLI JSON envelope contract.
- `mcp-contract-v1.schema.json` — MCP tool/resource/prompt catalog contract.
- `openapi/graph3d-apim.v1.json` — APIM-ready OpenAPI 3.1 contract.
